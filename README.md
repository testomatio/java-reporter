# Testomat.io Java Reporter <img src="img/logo.png" alt="drawing" width="35" style="vertical-align: text-top; margin-left: 5px"/>

This library is designed to make your Java project integration with Testomat.io reporter much easier and convenient.

## Version
- **0.1.0**

## 🔍 Compatibility

### Requirements

- **Java**: 11+
- **Build Tools**:
    - mvn 3.9.9 (recommended, but it supposed to work with 3.6+)

- **Test Frameworks**:
    - JUnit 5.6+ (no compatibility with 4)
    - TestNG 7.4+ (recommended. It's likely to work at least with 6.8)
    - Cucumber 7.0+ (2.x+ in theory, tested on 7.x+)

> **Note**: Other versions may work but are not explicitly tested.
> Please report compatibility issues in our [GitHub Issues](link).
